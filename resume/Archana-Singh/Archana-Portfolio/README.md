# Growth Livings — Portfolio

Independent Vercel root for the candidate portfolio experience. Deploy this folder as its own Vercel project. Set `VITE_API_URL` to the existing Savitri Livings backend origin (for example, `https://home-decor-0rfj.onrender.com`).

The profile is fetched from the centralized Growth Livings API. The site displays only profiles that are published and owner-approved. Until the source résumé is supplied and Archana approves the final content, the page shows a generic private state and is disallowed by `robots.txt`.
