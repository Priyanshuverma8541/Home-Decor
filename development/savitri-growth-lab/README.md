# Savitri Livings Growth Lab

An isolated, static development workspace based on the pasted Savitri Livings roadmap. It is a planning prototype, not a production integration.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server (for example, `python -m http.server 5177`).

## Scope and safety

- The live `frontend`, `backend`, `admin`, `marketing-cloud`, and archived projects are not imported or modified by this workspace.
- No Salesforce, Data Cloud, Marketing Cloud, AI provider, MCP server, customer data, API credentials, or production service is connected.
- Roadmap checklist state is stored in this browser's local storage only.
- The architecture is a proposal. Review privacy, consent, security, ownership, and operational readiness before implementing real integrations.
