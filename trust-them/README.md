# Trust Them — Growth Livings

Independent Vercel project root. Set `VITE_API_URL` to the existing Savitri Livings backend origin, then deploy this folder as a separate Vercel project.

The site uses the existing Savitri Livings account (`sl_token`), MongoDB, backend, and admin. Company and job pages only show records published by the admin; empty states are intentional. Profile visibility is private by default. Applications require explicit employer sharing consent.
