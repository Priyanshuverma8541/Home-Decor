# Savitri Livings Marketing Cloud

Standalone HTML, CSS, and JavaScript marketing workspace for audience selection, campaign planning, reusable email templates, social creative downloads, captions, and future analytics.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

The current build uses demo customers until the next backend integration step. It is ready to connect to the Savitri Livings customer API with admin authentication.

Live email delivery is intentionally configuration-gated. Add an approved email provider and sender credentials to the backend before enabling any actual send action.
